# Athenaeum

A knowledge normalization and synthesis pipeline. Captures content from arbitrary external sources, normalizes it into a uniform markdown representation, composes related records through merging, and synthesizes domain-specific reference works.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the full specification.
